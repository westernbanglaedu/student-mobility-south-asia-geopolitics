# White Paper HTML Outline

## Goal
Create a crawlable web version of the white paper so the research can support search visibility and LLM discoverability.

## Page purpose
- present the paper in readable HTML form
- give search engines indexable text
- link readers to supporting articles and conversion pages
- keep PDF available as a secondary downloadable asset

## Recommended page structure

### 1. Hero section
- title
- 2–3 sentence summary
- one clear line on the paper’s thesis
- CTA buttons:
  - Read summary
  - Download PDF

### 2. Executive summary block
- short version of the main findings
- 3–5 bullets maximum

### 3. Why this matters
- brief framing for students/parents/decision-makers

### 4. Main section navigation
Anchor links to:
- Method and limits
- South Asia overview
- Bilateral corridors
- Bangladesh–India deep dive
- Strategic insight
- Implications

### 5. Embedded paper content
Use HTML sections derived from the paper, not a PDF embed alone.

### 6. Evidence note block
Short note explaining:
- derived from structured evidence matrix
- metric differences kept explicit
- missing/conflicting values not normalized

### 7. Related reading section
Link to:
- pillar page
- key authority articles
- practical conversion pages

### 8. Final CTA block
Examples:
- Explore India study options from Bangladesh
- Read the full PDF
- View data-based guides

## SEO / metadata requirements

### Suggested title pattern
`Global Student Mobility and Security Dynamics in South Asia (2020–2025) | Data-Based White Paper`

### Suggested meta description angle
Data-based white paper on student mobility in South Asia from 2020–2025, focused on opportunity, disruption, and Bangladesh–India dynamics.

## Link requirements
- link to downloadable PDF
- link to at least 3 related authority articles
- link to at least 1 conversion-support page
- link back to the main pillar page

## Important rule
Do not publish the PDF without a readable HTML companion page.
